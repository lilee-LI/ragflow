## 概述

本测试方案覆盖 GaussDB DocEngine 的全文、向量、hybrid 检索与结果回读，对标技术设计 3.4 节、3.4.6 测试与验收。**第十一组为「作为 Text-to-SQL 失败后的兜底检索入口」**，呼应 Text-to-SQL 支路失败后由检索兜底的架构关系。

**环境标记**：每条用例「类型」带 `· 单元` / `· 集成`：
- `· 单元`：纯函数 / SQL 生成 / mock（5xx 结果字段、8xx FusionExpr、部分反向错误 mock）
- `· 集成`：需 `GAUSSDB_INTEGRATION=1` + 真实库（多数检索链路）

**字段继承**：未单列 Setup/Cleanup 的用例严格继承 [README 的 S/A/A/C 契约](README.md#setup--action--assert--cleanup-继承契约)，不得自行选择其它 fixture 或清理方式。

**测试范围**：
- `search` 入口与分支路由（单表 / 多表 / doc_meta 快速路径 / 聚合 / 混合拒绝 / kb_id 边界）
- 全文检索（simple parser、UGIN、coalesce ' '、6 字段加权、tie-breaker）
- 向量检索（TopK、内层 `<+>` ORDER BY、gsdiskann、valid 过滤、CTE 候选、threshold 外层、ANN 不可用即失败）
- hybrid 检索（权重进 SQL、min-max 归一、FULL OUTER JOIN、两 `%s` 同值、threshold 最终、只回表融合候选）
- metadata 组合（EXISTS / IN / CTE、不默认承诺 UGIN 命中）
- 结果字段与回读（`select_fields=[]` / 不含 id、cross-KB duplicate、invalid vector 不返回）
- aggregation / highlight
- rank feature 下推（pagerank_fea 下推、tag_feas 不进 GaussDB SQL）
- FusionExpr / `vector_similarity_weight`
- 兜底入口

**涉及文件**：`rag/utils/gaussdb_conn.py`、`common/doc_store/gaussdb_conn_base.py`、`rag/nlp/search.py`

**关键方法**：

| 方法 | 签名 | 说明 |
| --- | --- | --- |
| `search` | `(select_fields, highlight_fields, condition, match_expressions, order_by, offset, limit, index_names, knowledgebase_ids, agg_fields, rank_feature, **kwargs) -> SearchResult` | 入口，路由到各 builder |
| `build_search_sql` | `(table, select_fields, condition, keywords, vector, vector_dim, vector_weight, offset, limit, similarity_threshold, topn, highlight_fields, order_by, pagerank_weight) -> (sql, params)` | 按 keywords/vector 组合选 4 个 builder |
| `get_total` / `get_doc_ids` / `get_fields` / `get_scores` / `get_highlight` / `get_aggregation` | `(res, ...)` | 结果解析 |
| `normalize_select_fields` | `(fields) -> list[str]` | 空集补 id/kb_id |
| `Dealer.search` | `(req)` | GaussDB 读 `vector_similarity_weight`（默认 0.3）构造 FusionExpr |
| `Dealer.retrieval` | GaussDB 路径直接用 SQL 侧 `_score`，不本地 rerank |

**关键 SQL 约定**：

| 特性 | 片段 |
| --- | --- |
| 向量距离 | `q_{dim}_vec <+> %s::floatvector({dim})` |
| ANN 索引 | `USING gsdiskann (q_{dim}_vec COSINE)` |
| 全文索引 | `USING ugin(to_tsvector('simple', expression))` |
| 全文 parser | `to_tsvector('simple', ...)`、`plainto_tsquery('simple', %s)` |
| token NULL 保护 | `coalesce({column}, ' ')`（fallback `' '` 而非 `''`） |
| 全文 score | `10*ts_rank(title_tks)+5*ts_rank(title_sm_tks)+20*ts_rank(important_tks)+20*ts_rank(question_tks)+2*ts_rank(content_ltks)+1*ts_rank(content_sm_ltks)` |
| hybrid 融合 | `fts FULL OUTER JOIN vec ON kb_id, id` |
| min-max 归一 | `raw_fts_score / NULLIF(MAX(raw_fts_score) OVER(), 0)` |
| hybrid 权重 | `(1 - %s) * fts_score + %s * vector_score`（两个 `%s` 绑定同一值） |
| 稳定排序 | `score DESC, kb_id ASC, id ASC` |
| 向量 CTE | `WITH vec AS (... LIMIT candidate_limit) SELECT ... WHERE _score >= threshold` |
| pagerank 下推 | `(score_expr + COALESCE(pagerank_fea,0)/100.0 * %s)` |

**与 ES / OceanBase 对标差异（必须显式测试）**：

| 特性 | GaussDB | ES / OceanBase |
| --- | --- | --- |
| 融合权重来源 | `FusionExpr.weights` 读 `vector_similarity_weight`（默认 0.3） | ES 走 `_knn_scores` 二次调用；硬编码 `0.05,0.95` |
| 本地 rerank | 不做，直接用 SQL 侧 `_score` | OceanBase 依赖 chunk 向量本地 `rerank` |
| tsim/vsim | 均设为 sim（无法区分） | 可区分 |
| 全文 parser | 当前实现为 `simple` + `ngram` 双 UGIN；中文/英文/混合语义见 TC-RET-109 | ES 标准分词器 |
